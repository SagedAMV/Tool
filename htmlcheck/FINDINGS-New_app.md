## 3) تجربة أدوات مستودع Tool

| الأداة | النتيجة |
|---|---|
| `scripts/check-html.js` | ✅ تعمل. أعطت index.html تقييم 20% بسبب 4 «صور غير موجودة» — لكنها **نتائج خاطئة (false positives)**: المسارات `${c.photo}` و `${op.receipt}` و `${tempClientPhotoDataUrl}` هي **قوالب JS داخل template literals**، وليست مسارات ملفات حقيقية. |
| `scripts/visual-report.js` | 🔴 **بها خطأ خطير — انظر أدناه.** أعطت تقييم 100% (متساهلة جداً، لأنها تعتمد على HTMLHint فقط). |
| `scripts/serve.js` | لم يُختبر (خادم معاينة). |

### 🔴 خطأ خطير في `scripts/visual-report.js` (سطر 55)

```js
const outputPath = outputFlag ? resolve(outputFlag) : resolve('report-' + fileName.replace('.html', '.html'));
```

`fileName.replace('.html', '.html')` **لا يغيّر شيئاً**، والأسوأ أن `resolve()` بلا مجلد يعطي `report-index.html` في مجلد العمل — لكن عند تشغيل الأمر بمسار نسبي، الملف الناتج **كتب فوق `index.html` الأصلي** وأتلفه (190 KB → 3.6 KB). استعدت الملف من GitHub، والنسخة في المستودع سليمة، لكن **الخطأ ما زال موجوداً في الكود**.

**الإصلاح المقترح:**
```js
const base = fileName.replace(/\.html?$/i, '');
const outputPath = outputFlag
  ? resolve(outputFlag)
  : resolve(dirname(filePath), `report-${base}.html`);

if (resolve(outputPath) === resolve(filePath)) {
  console.error('❌ رفض: مسار التقرير يطابق الملف المصدر.');
  process.exit(1);
}
```

**اقتراح ثانٍ لـ `check-html.js`:** تجاهل أي `src`/`href` يحتوي `${` أو `{{` قبل التحقق من وجود الملف.

## 4) تحسينات أُضيفت لأداة htmlcheck في هذه الجولة

1. **`--isolate` (افتراضي)** — تعيد تحميل الصفحة قبل كل ضغطة، فلا تتراكم النوافذ المنبثقة وتحجب باقي الأزرار (كانت 12 ضغطة تفشل بـ timeout قبل الإصلاح).
2. **`close_overlays()`** — تضغط Escape وتبحث عن أزرار الإغلاق الشائعة.
3. **`is_covered()`** — تحدد بالضبط **أي عنصر** يحجب الزر، بدل رسالة timeout غامضة.
4. **كشف فتح النوافذ** — ترصد ظهور طبقة `fixed/absolute` كبيرة وتسجلها كنتيجة إيجابية للضغط.
5. **فلترة العناصر المرئية** — تفحص المرئي فقط وتُبلغ بعدد المخفي، بدل إهدار الوقت على عناصر داخل نوافذ مغلقة.
6. **ضغط قسري احتياطي** مع تسجيل واضح `⚠️ احتاج ضغطاً قسرياً`.
