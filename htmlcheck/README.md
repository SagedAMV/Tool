# htmlcheck — محاكاة وفحص ملفات HTML بمتصفح حقيقي

أداة تفتح ملف HTML في متصفح **Chromium حقيقي** (عبر Playwright)، تضغط الأزرار فعلياً،
تلتقط لقطات شاشة بأحجام مختلفة، وتُخرج تقريراً كاملاً عن الأخطاء والتنسيق والتصميم.

## ماذا تفحص؟

| # | الفحص |
|---|-------|
| 1 | تشغيل الصفحة في Chromium حقيقي (JS + CSS + الخطوط) |
| 2 | لقطات شاشة: موبايل 390×844، تابلت 820×1180، سطح مكتب 1440×900 (شاشة أولى + صفحة كاملة) |
| 3 | **الضغط الفعلي** على كل زر/رابط داخلي وتسجيل ماذا حدث (تغيّر DOM / تغيّر الرابط / لا شيء) |
| 4 | التقاط أخطاء JavaScript وأخطاء الكونسول |
| 5 | طلبات الشبكة الفاشلة (صور مفقودة، 404، CDN لا يعمل) |
| 6 | تجاوز أفقي (Horizontal overflow) وعناصر خارج الشاشة |
| 7 | نصوص أصغر من 11px |
| 8 | أزرار/روابط أصغر من 44px (سيئة على الجوال) |
| 9 | تباين ألوان ضعيف حسب معيار WCAG AA |
| 10 | صور بلا `alt`، غياب `meta viewport`، غياب `lang` |
| 11 | عناصر قابلة للنقر متداخلة فوق بعضها |

## التثبيت

```bash
pip install playwright
python -m playwright install --with-deps chromium
```

## الاستخدام

```bash
python htmlcheck.py index.html                 # فحص كامل
python htmlcheck.py index.html -o my_report    # تحديد مجلد الإخراج
python htmlcheck.py index.html --no-click      # بدون ضغط الأزرار
python htmlcheck.py https://example.com        # فحص موقع مباشر
python htmlcheck.py index.html --viewport 1920x1080 --viewport 360x740
```

### الخيارات
| الخيار | الوصف |
|---|---|
| `-o, --out` | مجلد الإخراج (افتراضي: `htmlcheck_report`) |
| `--no-click` | لا تضغط الأزرار |
| `--limit N` | أقصى عدد أزرار تُضغط (افتراضي 40) |
| `--wait MS` | مدة الانتظار بعد التحميل (افتراضي 1200ms) |
| `--viewport WxH` | مقاس مخصص، يمكن تكراره |

## المخرجات

```
htmlcheck_report/
├── report.html     ← التقرير الكامل (الصور مدمجة بداخله، افتحه بالمتصفح)
├── report.json     ← نفس النتائج بصيغة JSON للأتمتة
└── shots/          ← اللقطات الخام (قبل/بعد كل ضغطة)
```

## مثال حي

`examples/demo.html` صفحة فيها عيوب متعمّدة. شغّل:

```bash
python htmlcheck.py examples/demo.html -o demo_report
```

النتيجة الفعلية:

```
0  button  زر يعمل          -> تغيّر النص الظاهر
1  button  زر بلا وظيفة     -> لا تغيير ملحوظ (قد يكون الزر بلا وظيفة)
2  button  زر يسبب خطأ JS   -> ❌ خطأ JS: notDefinedFn is not defined
3  button  زر صغير          -> تغيّر النص الظاهر
4  button  زر معطّل          -> معطّل (disabled) - تم تخطيه
5  a       رابط داخلي       -> تغيّر العنوان إلى ...#section

تجاوز أفقي: 1 | نص صغير: 2 | أزرار <44px: 6 | صور بلا alt: 1 | تباين ضعيف: 3
```

## بدائل أخرى للمحاكاة (للعلم)

- **Playwright** (المستخدم هنا) — الأقوى: متصفح حقيقي، لقطات، نقر، شبكة.
- **Puppeteer** (Node.js) — مشابه، Chromium فقط.
- **Selenium** — أقدم، أبطأ، يحتاج WebDriver.
- **jsdom** (Node) — DOM وهمي بلا رسم، سريع لكن لا يفحص التصميم ولا يلتقط صوراً.
- **Lighthouse / axe-core** — لفحص الأداء وإمكانية الوصول (يمكن دمجها مع هذه الأداة).
